# Cap Templemars

Suivi personnel d'une recherche de logement près de Templemars : pistes classées par temps à vélo, trajet écrit et Google Maps pour chacune, messages polis adaptés à chaque contact, dossier de pièces.

Site publié : https://adebayo-moutalabi.github.io/cap-templemars/

Pour modifier le projet, ouvrez ce dossier dans Claude Code : `CLAUDE.md` décrit sa structure et ses règles. Chaque push sur `main` met le site à jour.
